# Aegis System Documentation & Implementation Guide

## Executive Summary & System Architectural Boundaries

**Aegis** is an autonomous multi-agent orbital collision de-confliction system built using a FastAPI + WebSocket backend and a React/Vite + `react-globe.gl` frontend. It automates satellite collision avoidance negotiations across operators using deterministic safety algorithms alongside LLM-driven operational narration.

### Architectural Invariants

1. **Deterministic Safety Calculations:** Any number affecting a safety decision ($\Delta v$, miss distance, `yield_score`) MUST originate strictly from deterministic Python routines—never directly from LLM text generation. The LLM serves solely for structured tool calling and operational narration.


2. **Decoupled Architecture:** `agents/` modules do not interact directly with WebSocket connections. The Orchestrator acts as the sole broadcasting hub and manager of session state.


3. **Data Routing:** The frontend never connects directly to third-party APIs. All telemetry and tracking feeds route through the backend, which operates offline-first using local cached data as its primary fallback.


4. **Single Globe Instance:** The UI uses a single configurable 3D Globe component across all visual modes (Monitor, Conjunction Highlight, and Trajectory Simulation).


5. **Capped Negotiation & Resilience:** Negotiation rounds are capped (default: 3) with a deterministic tie-break fallback. The Validation Agent can approve "no action". On WebSocket reconnect, clients always request full state snapshots. All timestamps are strictly UTC.

| Layer | Tool | Purpose |
| --- | --- | --- |
| **Backend framework** | FastAPI (Python 3.11+) | REST + WebSocket server, async-native

 |
| **Orbital propagation** | `sgp4` (Python) | Real SGP4 propagation from TLE data

 |
| **Data validation** | Pydantic | Schema enforcement for all agent messages and API payloads

 |
| **LLM** | Anthropic API (Claude), via `anthropic` SDK | Negotiation narration + structured tool-calling

 |
| **Negotiation state machine** | Hand-rolled enum/dispatch | Deterministic state flow without unforced framework risk

 |
| **Local persistence** | SQLite / plain JSON cache | Conjunction history, cached TLE/NOAA snapshots

 |
| **Frontend framework** | React + Vite | Fast dev server, client-side rendering

 |
| **Globe visualization** | `react-globe.gl` | 3D globe, points/arcs/rings layers for satellites, orbits, alerts

 |
| **Client-side propagation** | `satellite.js` (optional) | Smooth client-side orbit animation without full backend round-trips

 |
| **Styling** | Tailwind CSS | Fast theming, dark space aesthetic

 |
| **Frontend state** | Zustand | Lightweight store for live WebSocket state

 |
| **Language** | TypeScript (frontend), Python (backend) | Type-safe client, robust backend logic

## End-to-End Data Flow Execution

```
1. celestrak.py fetches/loads cached TLEs[cite: 12]
2. monitor_agent.py propagates via sgp4, detects conjunctions below threshold[cite: 12]
3. monitor_agent.py → emits ConjunctionAlert → orchestrator.py[cite: 12]
4. orchestrator.py → creates NegotiationSession, invokes two operator_agent.py instances[cite: 12]
5. Each operator_agent.py → computes yield_score via cost_functions.py (deterministic)[cite: 12]
                          → calls Anthropic API with yield_score as tool input → gets justification_text[cite: 12]
6. operator_agent.py → emits NegotiationMessage → orchestrator.py → broadcast over WebSocket[cite: 12]
7. orchestrator.py compares yield_scores after each round; on convergence or round cap →
   validation_agent.py re-runs sgp4 lookahead on proposed maneuver[cite: 12]
8. validation_agent.py → approves | rejects_secondary_risk | approved_no_action[cite: 12]
   → if rejected: loop back to step 5 with added constraint[cite: 12]
   → if approved: orchestrator.py emits Resolution → broadcast → frontend updates globe[cite: 12]
9. storage/db.py logs the full session for the History page[cite: 12]

```

## Core Component Patterns

### Deterministic Cost Calculation & LLM Narration (`backend`)

```python
# backend/app/agents/cost_functions.py
CONJUNCTION_THRESHOLD_KM = 5.0
HYSTERESIS_CLEAR_KM = 4.0
MAX_NEGOTIATION_ROUNDS = 3
VALIDATION_LOOKAHEAD_HOURS = 6

def compute_yield_score(mvi: float, fuel_margin_pct: float, maneuver_cost_delta_v: float) -> float:
    """Computes deterministic yield score. Higher score yields to lower score."""
    return (mvi * 0.5) + (fuel_margin_pct * 0.3) - (maneuver_cost_delta_v * 0.2)

```

```python
# backend/app/agents/operator_agent.py
import anthropic
from app.agents.cost_functions import compute_yield_score

client = anthropic.Anthropic()

async def get_agent_justification(agent_state: dict, delta_v: float) -> str:
    # Compute score deterministically BEFORE calling LLM
    yield_score = compute_yield_score(
        agent_state['mvi'], 
        agent_state['fuel_margin_pct'], 
        delta_v
    )
    
    try:
        response = client.messages.create(
            model="claude-sonnet-4-6",
            max_tokens=300,
            messages=[{
                "role": "user",
                "content": (
                    f"You are the negotiation agent for {agent_state['operator']}. "
                    f"Your computed yield_score is {yield_score:.2f} "
                    f"(MVI: {agent_state['mvi']}, Fuel: {agent_state['fuel_margin_pct']}%). "
                    "Write a concise 1-2 sentence operational justification for this position."
                ),
            }],
        )
        return response.content[0].text
    except Exception:
        # Fallback path ensures negotiation loop stability if LLM fails
        return f"Yield score calculated at {yield_score:.2f} based on current operational parameters."

```

### Workstream Allocations

* **Dev A (Orbital Physics):** TLE caching (`data/celestrak.py`), SGP4 orbital propagation, pairwise conjunction scanning (`agents/monitor_agent.py`), trajectory vector generation, SQLite history persistence (`storage/db.py`).


* **Dev B (System Spine & Orchestrator):** FastAPI application skeleton (`main.py`), WebSocket connection lifecycle (`orchestrator/websocket_manager.py`), event sequence tracking, session state machine execution (`orchestrator/orchestrator.py`).


* **Dev C (Agent Intelligence):** Deterministic `yield_score` algorithms (`cost_functions.py`), Anthropic LLM narration integration (`agents/operator_agent.py`), safety validation lookahead checking (`agents/validation_agent.py`).


* **Dev D (Frontend Experience):** Application shell, configurable `react-globe.gl` rendering, real-time negotiation console (`components/negotiation`), Zustand state store (`store/useNegotiationStore.ts`), client WebSocket hook (`lib/websocket.ts`).
