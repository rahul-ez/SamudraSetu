Project Background & Data Pipeline OverviewThe project combines four distinct raw data streams into a unified feature store:   Port Operational & Physical Attributes (Port_data.xlsx): Synthetic/rule-based operational logs (anchorage waiting times, congestion index, utilization, rail windows) and static port specifications (draft, beam, LOA, channel depth) for Newcastle Port and Paradip Port.   Short-Term Freight Spot Rates (freight_rates.csv): Historical route-level freight prices (2024–2026) across key dry-bulk corridors.   Macroeconomic Indicators (raw_commodity_macro.csv): Real-world historical financial time-series pulled from external market APIs:USD/INR Exchange Rate (INR=X): Yahoo Finance.   Brent Crude Oil (BZ=F): Yahoo Finance (Bunker fuel proxy).   Global Coal Benchmark (PCOALAUUSDA): Federal Reserve Bank of St. Louis (FRED) Newcastle coal price index.   Proxy Route Freight Index (raw_freight_routes.csv): Generated via Geometric Brownian Motion (Random Walk with $1.5\%$ daily volatility limit) anchored to baseline nautical distances and vessel class capacity limits.   2. Execution Script (merge_all_data.py)Ensure all raw input files (raw_commodity_macro.csv, raw_freight_routes.csv, freight_rates.csv, and Port_data.xlsx) sit in the same working directory, then run:   Pythonimport pandas as pd

# 1. Load Macro Data
df_macro = pd.read_csv('raw_commodity_macro.csv')
df_macro['date'] = pd.to_datetime(df_macro['date']).dt.strftime('%Y-%m-%d')

# 2. Load Generated Freight Routes Data
df_rfr = pd.read_csv('raw_freight_routes.csv')
df_rfr['date'] = pd.to_datetime(df_rfr['date']).dt.strftime('%Y-%m-%d')

# 3. Load Freight Rates Data & Pivot
df_fr = pd.read_csv('freight_rates.csv')
df_fr['date'] = pd.to_datetime(df_fr['date']).dt.strftime('%Y-%m-%d')
fr_pivoted = df_fr.pivot_table(index='date', columns=['route', 'vessel_class'], values='rate_usd_per_mt')
fr_pivoted.columns = [f"freight_{r.replace('-', '_').lower()}_{v.lower()}_usd_per_mt" for r, v in fr_pivoted.columns]
fr_pivoted.reset_index(inplace=True)

# 4. Load Port ML Training Data
df_ml = pd.read_excel('Port_data.xlsx', sheet_name='ML_Training_Data', header=3)
df_ml['date'] = pd.to_datetime(df_ml['date']).dt.strftime('%Y-%m-%d')

# 5. Merge Daily Macro & Freight Time Series
df_master = pd.merge(df_macro, df_rfr, on='date', how='left')
df_master = pd.merge(df_master, fr_pivoted, on='date', how='left')
df_master.to_csv('master_macro_freight_daily.csv', index=False)

# 6. Merge Port Dataset with Time Series Master
df_port_master = pd.merge(df_ml, df_master, on='date', how='left')
df_port_master.to_csv('master_port_ml_dataset.csv', index=False)

print("SUCCESS: Generated master_port_ml_dataset.csv and master_macro_freight_daily.csv")
5. Notes for Downstream Agent / DeveloperMissing Value Strategy: On non-trading days/weekends, market indicators (brent_crude_usd_per_bbl, coal_price_usd_per_mt) contain minor NaN values. Apply forward-fill (ffill()) before training.   Train/Validation Splitting: Perform chronological time-based splitting (e.g., Train: Jan–Sep 2025, Test: Oct–Dec 2025) rather than random $K$-fold cross-validation to prevent data leakage.Feature Scaling: Tree-based models (XGBoost, LightGBM) do not require feature scaling, but neural network baselines or distance-based algorithms must scale numerical features (congestion_index_0_100, sim_wait_hours, freight rates).
